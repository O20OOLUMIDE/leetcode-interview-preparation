# LeetCode Interview Preparation

## About

This repository documents my journey of preparing for software engineering technical interviews through consistent LeetCode practice.

Rather than focusing on completing as many questions as possible, my goal is to build strong problem-solving skills and develop a deep understanding of algorithms, data structures, and Python. Every solution in this repository represents an opportunity to improve my logical thinking, debugging ability, and coding style.

As an aspiring Software Engineering Degree Apprentice, I believe that becoming a great engineer is about understanding *why* a solution works, not just memorising it. Whenever possible, I solve problems independently before reviewing alternative approaches, allowing me to learn from mistakes and strengthen my problem-solving process.

---

## Goals

- Develop strong algorithmic thinking.
- Improve Python programming skills.
- Prepare for technical interviews.
- Learn efficient data structures and algorithms.
- Build confidence solving unfamiliar problems.
- Track my progress over time.
- Demonstrate consistent learning and improvement.

## Learning Approach

For every problem I aim to:

- Understand the problem before writing code.
- Design my own solution first.
- Debug and improve my code independently.
- Learn the time and space complexity.
- Compare my approach with more efficient solutions.
- Reflect on what I learned before moving on.

This repository is intended to show my learning journey, not just a collection of accepted solutions.
